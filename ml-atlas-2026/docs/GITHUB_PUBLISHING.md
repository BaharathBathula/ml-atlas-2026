# GitHub publishing steps

```bash
cd ml-atlas-2026
git init
git add .
git commit -m "Initial commit: ML Atlas 2026"
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/ml-atlas-2026.git
git push -u origin main
```

Recommended repository settings:
- Description: `Interactive ML taxonomy, algorithm playground, model recommender, Docker, tests, and CI.`
- Visibility: Public
- Add topics from the README.
- Enable GitHub Actions.
- Add a screenshot/GIF after running the app.
