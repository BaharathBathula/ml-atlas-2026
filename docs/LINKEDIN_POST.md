I just built **ML Atlas 2026** — an interactive machine-learning taxonomy and algorithm playground.

Instead of leaving a machine-learning roadmap as a static diagram, I converted it into a working software project with:

• an interactive ML taxonomy explorer  
• runnable classification, regression, clustering, dimensionality-reduction, and ensemble demos  
• automatic task-specific evaluation metrics  
• a practical algorithm recommender  
• modular Python architecture  
• unit tests and GitHub Actions CI  
• Docker support  
• a Streamlit interface for hands-on exploration  

One design decision mattered: I did **not** pretend that every branch of modern ML can be meaningfully implemented in one lightweight repository. Deep learning, reinforcement learning, self-supervised learning, generative AI, GNNs, and probabilistic graphical models are represented as structured learning paths and extension points, while the executable playground focuses on representative algorithms that can run reliably on a normal machine.

The goal was to turn an ML concept map into something engineers can actually explore, test, and extend.
